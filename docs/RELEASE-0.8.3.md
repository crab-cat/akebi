# akebi 0.8.3 — PDF++ rectangle references

- Question cards can attach a native PDF++ page/rectangle as metadata, next to choices, explanations and tips.
- Source links use the original PDF, with no duplicate raster files.
- A fixed preview uses the Obsidian/PDF++ Markdown renderer. The source button navigates to the exact PDF region.
- Accept pasted rectangle links or use the clipboard button after PDF++ selection.
- Renaming PDF files retains page, coordinates and width in linked card metadata.
- Existing raster images, old card formats, native SR schedules and learning histories are unchanged.
- No private biology course PDFs or study notes are distributed with the open-source release.
