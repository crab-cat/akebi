# akeBi 0.8.0

Initial standalone release. Desktop and mobile learning no longer require another spaced-repetition plugin. Includes local Markdown flashcards, four-choice and swipe review, bounded study batches, adaptive evidence and review recommendations, and guided phrase assembly with fixed boundaries and at most 15 candidates.

Legacy RMUX card metadata and SR comments remain readable. Import from Repetition Mobile UX is explicit and non-destructive. User settings/history, dictionaries, course notes and former mascot GIFs are not included in this release.

Critical regression tests cover reconstruction, negation, real DOM selection, timeout persistence and migration safety. The constrained exercise bank was also replayed on 375px and 1280px browser layouts. A physical iPhone has not been remotely inspected.
